# 项目名称：🔱TZ-MultiAgent-Oracle-System🔱
核心功能描述：
1. 本系统采用多代理（Multi-Agent）架构，将 2026 丙午年（赤马红羊劫/离火九运开启） 作为全局最高测算标准，通过以下逻辑实现精准的未来演化预演：
2. 流年太岁权重引擎 (Global Year Standards)：
  系统不再孤立看命盘，而是将 2026 丙午年（极旺火运） 作为强制测算背景。
  八字维度：自动带入流年干支对原局的冲克（如：火旺对喜金水者的压制）。
  紫微维度：根据 2026 丙干四化（天同化禄、廉贞化忌等）精准定位流年风险宫位。
3. 多代理合参收敛：
  八字：定性底层水位。
  紫微：定位人事坐标。
  年份背景：定性大环境（离火九运之始），作为全局修正因子。
  塔罗：捕捉当下主观心态产生的微小变量。

4. 过程透明化交互：
  实时展示计算链路：从流年背景探测到多维度算力分析，增强用户信任感。
  清屏瞬展：最终清空中间逻辑，呈现高度收敛、以“阁下”为中心的沉浸式【命运剧本】。
5. 正向因果叙事：
  强制输出具有行动价值的指引，包含具体的月份（如农历五月流火月）、贵人方位及避险动作。

# How to get Google Gemini API Key

2. After the environment setup, run "pip install -U google-genai python-dotenv" in Command Line.
