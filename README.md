# 项目名称：🔱TZ-MultiAgent-Oracle-System🔱
本系统的核心意图并非简单的“预知未来”，而是利用 AI 算力在迷茫的时空节点为用户提供正向锚定。
1. 化焦虑为行动 (From Anxiety to Action)： 命理不应是沉重的枷锁。系统通过 Agent 4 的智慧合参，将复杂的命理波折转化为具体的“行动指南”。我们相信，当风险被具象化为“避险动作”，当机遇被细化为“月份与方位”，未知的恐惧便会转化为掌控感。
2. 正向因果叙事 (Positive Narrative)： 我们强制系统执行“转祸为福”的叙事逻辑。即便在 2026 丙午火旺的冲击下，系统也会引导用户看到“淬炼”背后的生机，强调**“心随境转”**。
3. 科技向善 (Tech for Well-being)： 在信息过载的时代，本工具旨在为用户提供一个静心思考的契机。所有的推演结果均以“引导用户往好了想、往对了做”为终极目标，致力于成为一个具有心理安抚效能的智慧伴侣。

## 核心功能描述：
1. 本系统采用多代理（Multi-Agent）架构，将年运，如2026丙午年（赤马红羊劫/离火九运开启）作为全局最高测算标准，通过以下逻辑实现精准的未来演化预演：
2. 流年太岁权重引擎 (Global Year Standards)：
  系统不再孤立看命盘，而是将 2026 丙午年（极旺火运） 作为强制测算背景。
  八字维度：自动带入流年干支对原局的冲克（如：火旺对喜金水者的压制）。
  紫微维度：根据年份丙干四化（天同化禄、廉贞化忌等）精准定位流年风险宫位。
3. 多代理合参收敛：
  八字：定性底层水位。
  紫微：定位人事坐标。
  年份背景：定性大环境（如：离火九运之始），作为全局修正因子。
  塔罗：捕捉当下主观心态产生的微小变量。
4. 过程透明化交互：
  实时展示计算链路：从流年背景探测到多维度算力分析，增强用户信任感。
  清屏瞬展：最终清空中间逻辑，呈现高度收敛、以“阁下”为中心的沉浸式【命运剧本】。
5. 正向因果叙事：
  强制输出具有行动价值的指引，包含具体的月份（如农历五月流火月）、贵人方位及避险动作。
